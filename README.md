# 🚀 Shankar Kongari — Portfolio Website

A modern, dark, futuristic portfolio website showcasing my journey as a B.Tech Computer Science student and aspiring AI Engineer. Built with vanilla HTML, CSS, and JavaScript — no frameworks, pure craftsmanship.

## ✨ Features:

- 🎨 **Dark Futuristic Theme** — Black + deep blue base with electric blue, cyan & purple neon accents
- 🌌 **Particle Animation** — Interactive neural-network-style canvas with mouse tracking
- 🪟 **Glassmorphism Cards** — Frosted glass UI elements with subtle glow borders
- 📊 **Animated Skill Bars** — Progress bars that animate on scroll
- 📱 **Fully Responsive** — Mobile-first design with smooth breakpoints
- ⚡ **Smooth Scroll Reveal** — Elements fade in as you scroll using IntersectionObserver
- 📬 **Working Contact Form** — Integrated with Web3Forms for real email notifications
- 🤖 **AI-Inspired Design** — Orbiting tech illustration, typing effect, futuristic typography

---

## 🛠️ Tech Stack

- **HTML5** — Semantic markup & SEO best practices
- **CSS3** — Custom properties, gradients, glassmorphism, keyframe animations
- **JavaScript** — Canvas API, IntersectionObserver, Fetch API
- **Google Fonts** — Orbitron (headings) + Inter (body)
- **Font Awesome** — Icon library
- **Web3Forms** — Contact form email delivery
